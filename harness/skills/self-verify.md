# Skill: self-verify

## 3회 루프

### 1회차 — 데이터 반박
- "이 수치의 출처는? 최신인가? 다른 소스와 일치하는가?"
- 불일치 발견 시 → 재검색 후 수정

### 2회차 — 시나리오 반박
- "Bear 시나리오가 현실화되면 손실은 얼마인가?"
- "지난 5년 유사 국면에서 결과는?"

### 3회차 — 행동경제학 반박
- 사용자의 `memory.md > 편향`을 꺼내서 자기 비판
- "확증 편향에 빠진 추천은 아닌가?"
- "최근 뉴스 휩쓸림(recency bias) 아닌가?"

## 판정
- 3회 모두 반박 무력화 → **통과**
- 1회라도 보강 필요 → **보류** (보강 후 재실행)
- 1회라도 결정적 반박 → **기각** (추천 철회)

판정 결과를 직전 응답의 §4 자가검증 블록에 기록.
